# Group-19: 全球知识生产的规律洞察

基于 Nature Human Behaviour (2022) 论文的交互式数据可视化网站，展示全球科学知识生产的结构、演变与不平等。

项目包含五个章节：全球科学能力的空间分布、学科之间的关联结构、国家科研结构的发展路径、四十年结构演变趋势，以及总结与讨论。数据覆盖 1973–2017 年 217 个国家、143 个学科，共计约 3500 万篇论文。
